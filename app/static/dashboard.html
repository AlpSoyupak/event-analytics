Architecture — What's Running
🌐
FastAPI API port 8000
Validates requests, enforces rate limits via Redis, writes to PostgreSQL, publishes to Kafka
↓
🗄️
PostgreSQL port 5432
Source of truth. Composite indexes on (tenant_id, received_at). BRIN index for time scans. GIN index for JSONB. Materialized views for fast aggregations.
↓          ↓
⚡
Redis port 6379
Rate-limit sliding windows. Analytics cache (TTL 60–300s). Daily quota counters.
📨
Kafka port 29092
Event stream. External producers send here. Consumer batch-inserts into PostgreSQL.
↓
⚙️
Celery Worker + Beat Flower: port 5555
Beat scheduler triggers REFRESH MATERIALIZED VIEW CONCURRENTLY every 5 min. Nightly cleanup deletes events past 90-day retention window.
